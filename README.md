# Nonlinear Toolbox

A research-oriented nonlinear dynamics toolbox focused on
one-dimensional maps, chaos diagnostics, and symbolic dynamics.

Implements:

* logistic map
* Lyapunov exponent
* bifurcation diagrams
* spectral diagnostics
* symbolic dynamics

## Install

```
pip install -r requirements.txt
```

## Run examples

```
python examples/logistic_bifurcation_demo.py
python examples/lyapunov_demo.py
python examples/symbolic_dynamics_demo.py
```

## Run tests

```
pytest
```
